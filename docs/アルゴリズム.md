## 0. ことば

### 席
- 席は (r, c)。r＝列（前から 1, 2, …, R）、c＝席（1〜4）
- c=1,2 が**入口側**（左）、c=3,4 が**運転席側**（右）。c=1 と c=4 が窓側、c=2 と c=3 が通路側
- 最後部の列 R だけ 5席（c=1〜5）。**最後部の真ん中**は (R, 3)
- 業務席: (1, 3) (1, 4)。ドライバー2人のときは (1, 1)〜(1, 4)（→ #7）
- **横ペア**: 同じ列の (r,1)(r,2) か (r,3)(r,4)。**通路またぎ**: (r,2)(r,3)

```
        入口側        運転席側
 1列   [1][2]   通路   [業][業]
 2列   [1][2]          [3][4]
 ...
 R列   [1][2][3][4][5]          ← (R,3) が最後部の真ん中
```

### 組とかたち
- 組 g: 人数 n、性別（男・女・不明）、前席オプション
- 組 g のある日の**かたち**: 列ごとの人数を前から並べたもの。例: 5名が 4列目に3人・5列目に2人 → `[3,2]`
- **縦並び**: 同じ組が、続いた2つの列にそれぞれ1人ずつ座っている（かたちに `1,1` が続けて出る）
- **鍵席**: 3名の `[2,1]` か `[1,2]`（L字）
- **相席**: 1つの横ペアに、ちがう組の2人が座っている

## 4. 全体の並べ方

### 4.1 日ごとの持ち場（どの列のあたりに座るか）
- **1日目**: 申し込み順に、前から
- **2日のツアー**: 2日目は**前後を反転し、左右も入れ替える**（添乗員さん）
- **3日以上のツアー**: 列を前・中・後ろの3つ（①②③）に分け、毎日回す。毎日、左右も入れ替える
  - 1日目 ①②③ ／ 2日目 ②③① ／ 3日目 ③①② 【要確認: 添乗員さんは「4日目③②①」と書いた。4日目以降の回し方】
  - 3分割は「ざっくり」。組を割ってまで列の区切りにそろえない
- 前席オプション組は、毎日前3列の中で回す（今の仕様7）

### 4.2 置き方（1日ぶん）
1. 組を、その日の持ち場の順に並べる（4.1）
2. 1組ずつ、前から、**2章の1番のかたち**で置ける最初の列に置く（今のテトリス方式の規則「本来のかたちを保てるなら、より前の列」）
3. 置けない組が出たら、次の順で試す。どれも**絶対の決まり（1章）を破らない範囲**でだけ行う
   1. その組を後ろへ送り、うしろの組を前へ出す（順番の入れ替え。ずれは小さいほどよい）
   2. 1人参加・奇数の組で、すき間を埋める（S2）
   3. 2章の2番、3番のかたちにする
   4. 最後部の真ん中を使う（C1）
4. それでも置けなければ、**置けなかった組を警告に出して止める**（縦並びや泣き別れで無理に押し込まない）

### 4.3 出来ばえの比べ方（よいほうを採る。上の項目ほど重い）
1. 1章の違反 0（必須）
2. 前席オプション組が前3列にいる
3. 2章の1番のかたちの組が多い
4. 相席が少ない／最後部の真ん中を使っていない
5. その日の持ち場からのずれが小さい
6. 申し込み順からのずれが小さい
