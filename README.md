# バス座席表メーカー（bus-seat-maker）

バスツアーの**添乗員向け**の座席表ジェネレータです。申し込みグループを順番に入れると、席を自動で割り振り、A4縦・1日1ページで印刷できる座席表にします。

手書きで作っていた「グループごとにマーカーで大きく囲み、その中に名前と人数を1回書く」座席表を、画面の上で作れるようにしたものです。グループの席は必ず**連続した四角いブロック**になり、斜めに泣き別れることはありません。

非営利団体 **AIかけこみ寺** が制作し、**MITライセンス** で公開しています。

## 動かし方

このツールは**完全な静的サイト**です。サーバーもデータベースも外部ライブラリも使いません。入力した内容は**あなたのブラウザの中（localStorage）だけ**に保存され、インターネットには一切送信されません。

`index.html` をブラウザで開くだけで動きます（ダブルクリックで開く `file://` でも動作します）。

ローカルサーバー経由で開きたい場合は次のとおりです。

```
python3 -m http.server 8000     # Mac / Linux（Windows は python -m http.server 8000）
npx --yes http-server -p 8000   # Node.js を使う場合
```

そのあとブラウザで <http://localhost:8000/> を開きます。

対応ブラウザ：PC の Chrome / Edge 最新版。

### 使う流れ

1. 「見本を入れてみる」を押して、動きを確かめる
2. ツアー名・号車・日数・出発日を入れる
3. 座席の形（11列45席／12列49席）を選ぶ
4. 申し込みグループを**申し込み順に**追加する（人数・男女・前席オプション。名字の欄はお名前を出す設定にしたときだけ出ます）
5. 座席表が自動でできる。必要なら席を2回押して**手で入れ替える**
6. 「印刷する」でA4縦・1日1ページの座席表を印刷／PDF保存する

**操作方法がわからないときは、まず [`manual.html`](manual.html) を開いてください。** このREADMEより平易に説明しています。

## 席の決め方（ルール11本）

席の割り当ては `js/seat.js` の純粋関数にまとまっています（画面の処理とは分離しているので、テストから直接呼べます）。

| # | ルール | 実装 |
|---|---|---|
| 1 | 最前列の運転席側（右）2席は業務席。お客様は配置しない | `buildLayout()` の `isCrew` |
| 2 | 最後部列のみ5席、それ以外は4席（左2＋右2） | `buildLayout()` |
| 3 | 申し込み順に前から詰める | `assignDay()` のグループ順 |
| 4 | **グループは必ず連続した四角いブロックに入れる**（斜めに割れない） | `findRect()` |
| 5 | 端数が出るときは、四角を保つためそのグループ用の空席を確保する（3名→2席×2列に3名＋空席1） | `reserved` / `MAX_WASTE` |
| 6 | 前席オプションのグループを先に、前から3列目までに配置。溢れたら以降の列へ回し警告 | `FRONT_ROWS` / `front-overflow` |
| 7 | 相席が発生する場合、男女が同席にならないよう性別を合わせる | `planMembers()` / `genderCompatible()` |
| 8 | 空席に余裕がある（奇数グループの端数を空席で吸収できる）ときは相席を作らない | `shouldAvoidSharing()` |
| 9 | 日ごとにグループの並べ始めを1周ぶんの `d/日数` だけずらす（巡回シフト）。**配置そのものは常に前から詰める**（後方に空白の島を作らない）。前席オプションのグループはずらす対象外 | `startIndexForDay()` |
| 10 | 使われない後方のかたまりは、まとめて1つの「自由席」の枠にする | `freeAreaBlock()` |
| 11 | 隣接（左右・前後）するグループが同色にならないよう6色を割り当てる | `buildColors()` |

### ブロックの形の選び方

`findRect()` は「いちばん前の列」を最優先し、同じ列のなかでは次の点数がいちばん小さい四角を選びます。

```
点数 = 横幅ペナルティ + 列数 × 0.4 + 空ける席数 × 0.6
横幅ペナルティ: 2席=0 / 4席=0.5 / 3席=3 / 1席=4
```

結果として、2名→2席×1列、3名→2席×2列（1席空き）、4名→2席×2列の正方形、5名→2席×3列（1席空き）、8名→4席×2列（通路を跨ぐ2列ぶん）になります。通路を跨ぐブロックは、左右をひとつながりの枠で囲んで表現します。

四角が1つで作れないときだけ、入るかぎり大きい四角に分割し（各断片は同色の枠で表示）、`split` の注意を出します。表示ラベル（名前＋人数の丸数字）は**ブロックの中に1回だけ**描きます。

### 日ごとの席替え（巡回シフト）

前席オプションを除いたグループの並びを**輪（循環リスト）**とみなし、d日目（0起点）は全体の `d / 日数` だけ進んだ位置から並べ始めます。開始位置は**人数ベース**で、累積人数が `総人数 × d / 日数` に達する最初のグループの切れ目です（グループを途中で切ることはありません）。

```
例：8組×4名＝32名
  2日ツアー → 開始グループ 0, 4       （半周ずつ）
  4日ツアー → 開始グループ 0, 2, 4, 6 （4分の1ずつ）
例：9組×3名＝27名
  3日ツアー → 開始グループ 0, 3, 6    （3分の1ずつ。全員が前・中・後を1日ずつ）
```

2日ツアーは半周シフトとなり、従来の「前後入れ替え」とほぼ同じ結果になります。配置は**どの日も前から詰める**ため、後方に不自然な空白の島はできません。

### 表示ラベルの規則

- 既定は自動ラベル `お客様①`（申し込み順の番号）。**個人名はPIIなので既定では出しません**。この設定では**名字の入力欄そのものを画面に出しません**
- 実名表示をONにしたときだけ名字の欄が現れ、`名字＋様` で表示します。**同姓が複数いる場合は自動でフルネーム表示**に切り替わります（OFFに戻しても入力値は保持）
- グループ人数は丸数字（`②` = 2名）で、**ブロックの枠内に1回だけ**表示します

### 設計上の判断

- **既定で個人名を出さない**：座席表は紙で持ち歩くもので、落とすことも置き忘れることもあります。番号での運用を既定にし、実名表示は明示的なトグルにしました。
- **グループは1つの大きな枠**：実物（手書きの座席表）は座席ごとではなくグループ全体を1本のマーカーで囲み、その中に名前と人数を1回書きます。座席ごとにラベルを繰り返すより、現場で読み取りやすいのでこの形にしました。
- **端数は空席で四角を保つ**：3名グループに2席×2列を割り当て、1席を空けます。手書き運用と同じで、四角が崩れません（席が窮屈なときは自動でこの余裕をやめます）。
- **日ごとの席替えは「順番をずらす」で行う**：後ろから詰めると後方に不自然な空白の島ができるため、配置は常に前詰めのまま、グループの並べ始めだけを人数の割合ぶんずらします（巡回シフト）。2日でも3日でも同じ考え方で扱えます。
- **お名前の入力欄は既定で出さない**：実名表示をONにしたときだけ名字の欄が現れます（入力済みの値はOFFにしても保持）。番号運用が既定であることを、画面の作りからも伝えるためです。
- **前席オプションはずらす対象外**：料金をいただいている以上、どの日も前3列に置くのが筋と判断しました。仕様として固定しています。
- **性別未入力は誰とでも相席可**：分からないものを勝手に決めつけないための扱いです。相席が起きそうなときは入力してください。
- **判定できないことは判定しない**：年齢・体調・個別のご要望などは機械には分かりません。手動入れ替えで添乗員が最後に決める前提です。

## 情報がどこに行くか

- **ふだんの利用は端末内で完結します。** 静的ファイルだけで動き、送信先のサーバーもデータベースもありません。入力したお名前・人数・男女の別も、作った座席表も、ブラウザの外には出ません（保存先はlocalStorageのみ）。
- **AIにカスタマイズを頼むときだけ、流れが変わります。** 渡したフォルダの中身は、あなたが契約しているAI事業者に送られます。AIかけこみ寺には何も渡りません。
- お客様の情報を扱うなら、**入力が学習に使われない設定・プラン**（ChatGPTの学習オフ設定、Claude・Geminiなどの有料/法人プラン等）で使うことをおすすめします。条件は各社で変わるため、提供元の案内を確認してください。
- **AIに改造を頼むときは、お客様の情報が入っていない状態で渡してください。** 画面の「グループを全部消す」を押してからフォルダを渡すのが安全です。
- 「保存ファイル」にはお名前や男女の別が入ります。**個人情報として扱ってください**（共有フォルダに置きっぱなしにしない、不要になったら消す）。`.gitignore` で `*_座席表データ.json` をgitの管理対象外にしてあります。

詳しくは [`manual.html` の8章冒頭](manual.html#data-flow) にあります。

```

まず、ソースを手元に用意してください。

- 置き場所: https://github.com/ai-kakekomi/bus-seat-maker
- 手元にまだ無ければ、作業用フォルダに git clone してください
- すでに手元にあれば、git pull で最新に更新してください（私が加えた変更は消さないでください）
- 用意できたら中身をひととおり読んで、このツールが何をするものか、
  席の決め方がどのファイルに書いてあるかを、日本語でかんたんに教えてください
- 最後に、ローカルサーバー（例: python3 -m http.server 8000）で開いて、
  画面がちゃんと表示されることを確認してください
- 作業を始める前に、渡したフォルダにお客様の個人情報や社外秘の情報が
  入っていないか、私に確認してください
```

そのあとは、やりたいことを日本語で頼むだけです。

- 「中型バスの9列33席を選べるようにして」
- 「業務席を最前列の左1席だけにして」
- 「前席オプションの範囲を前から5列目までにして」
- 「日ごとの席替えを、順番をずらすのではなく左右の入れ替えにして」
- 「『車いすをご利用』のチェックを足して、その方は最前列の通路側にして」
- 「座席表の見出しに集合時刻の欄を足して、印刷にも出して」

改造したら「テストを流して、全部通ることを確認して」と頼んでください。おかしくなったら「さっきの変更を全部取り消して」で戻ります。
