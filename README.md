# バス座席表メーカー（bus-seat-maker）

バスツアーの**添乗員向け**の座席表ジェネレータです。申し込みグループを順番に入れると、席を自動で割り振り、A4縦・1日1ページで印刷できる座席表にします。

手書きで作っていた「グループごとにマーカーで囲む座席表」を、画面の上で作れるようにしたものです。

非営利団体 **AIかけこみ寺** が制作し、**MITライセンス** で公開しています。

- 座席図は**一般的な大型観光バスを想定した簡略図**です。実在の車両とは異なる場合があります。
- 男女の別・人数・オプションの有無は**入力された内容をそのまま扱います**。入力の誤りは検出できません。

### 対応している範囲

| | |
|---|---|
| 対応 | 11列45席／12列49席（通路をはさみ左2席＋右2席、最後部列のみ5席） |
| 対応 | 最前列の運転席側（右）2席を業務席として配置対象外にする |
| 対応 | 前席オプション（有料）のグループを前から3列目までに配置 |
| 対応 | 相席時の男女分離、空席に余裕があるときの相席回避 |
| 対応 | 複数日ツアー（2日目は前後反転、以降は交互） |
| 対応 | グループごとの色分け（6色。隣接グループは別色） |
| 対応 | 手動での座席入れ替え、A4縦・日別1ページの印刷／PDF保存 |
| **非対応** | サロン席・補助席・車いす対応席・トイレ付き車両などの特殊な配置 |
| **非対応** | 年齢・体調・車窓の見え方など、お客様の個別事情の考慮 |
| **非対応** | 予約システム・名簿ファイルからの取り込み、お客様への通知 |

## 動かし方

このツールは**完全な静的サイト**です。サーバーもデータベースも外部ライブラリも使いません。入力した内容は**あなたのブラウザの中（localStorage）だけ**に保存され、インターネットには一切送信されません。

`index.html` をブラウザで開くだけで動きます（ダブルクリックで開く `file://` でも動作します）。

ローカルサーバー経由で開きたい場合は次のとおりです。

```
python3 -m http.server 8000     # Mac / Linux（Windows は python -m http.server 8000）
npx --yes http-server -p 8000   # Node.js を使う場合
```

そのあとブラウザで <http://localhost:8000/> を開きます。

対応ブラウザ：PC の Chrome / Edge 最新版。

### 使う流れ

1. 「見本を入れてみる」を押して、動きを確かめる
2. ツアー名・号車・日数・出発日を入れる
3. 座席の形（11列45席／12列49席）を選ぶ
4. 申し込みグループを**申し込み順に**追加する（人数・男女・前席オプション・名字）
5. 座席表が自動でできる。必要なら席を2回押して**手で入れ替える**
6. 「印刷する」でA4縦・1日1ページの座席表を印刷／PDF保存する

**操作方法がわからないときは、まず [`manual.html`](manual.html) を開いてください。** このREADMEより平易に説明しています。

## 席の決め方（ルール9本）

席の割り当ては `js/seat.js` の純粋関数にまとまっています（画面の処理とは分離しているので、テストから直接呼べます）。

| # | ルール | 実装 |
|---|---|---|
| 1 | 最前列の運転席側（右）2席は業務席。お客様は配置しない | `buildLayout()` の `isCrew` |
| 2 | 最後部列のみ5席、それ以外は4席（左2＋右2） | `buildLayout()` |
| 3 | 申し込み順に前から詰める | `assignDay()` のグループ順 |
| 4 | 前席オプションのグループを先に、前から3列目までに配置。溢れたら以降の列へ回し警告 | `FRONT_ROWS` / `front-overflow` |
| 5 | グループはできるだけひとかたまりに配置する | `findSameGroup()` |
| 6 | 相席が発生する場合、男女が同席にならないよう性別を合わせる | `findShareable()` / `genderCompatible()` |
| 7 | 空席に余裕がある（奇数グループの端数を空席で吸収できる）ときは相席を作らない | `shouldAvoidSharing()` |
| 8 | 2日目は前後反転。3日目以降は交互。前席オプションのグループは反転対象外 | `assignDay({reversed})` |
| 9 | 隣接（左右・前後）するグループが同色にならないよう6色を割り当てる | `buildColors()` |

表示ラベルの規則：

- 既定は自動ラベル `お客様①`（申し込み順の番号）。**個人名はPIIなので既定では出しません**
- 実名表示をONにしたときだけ `名字＋様`。**同姓が複数いる場合は自動でフルネーム表示**に切り替わります
- 各席にグループ人数を丸数字（`②` = 2名）で表示します

### 設計上の判断

- **既定で個人名を出さない**：座席表は紙で持ち歩くもので、落とすことも置き忘れることもあります。番号での運用を既定にし、実名表示は明示的なトグルにしました。
- **前席オプションは反転対象外**：料金をいただいている以上、どの日も前3列に置くのが筋と判断しました。仕様として固定しています。
- **性別未入力は誰とでも相席可**：分からないものを勝手に決めつけないための扱いです。相席が起きそうなときは入力してください。
- **判定できないことは判定しない**：年齢・体調・個別のご要望などは機械には分かりません。手動入れ替えで添乗員が最後に決める前提です。

Node.js があれば実行できます。**外部パッケージは不要です。**

```

```

## 情報がどこに行くか

- **ふだんの利用は端末内で完結します。** 静的ファイルだけで動き、送信先のサーバーもデータベースもありません。入力したお名前・人数・男女の別も、作った座席表も、ブラウザの外には出ません（保存先はlocalStorageのみ）。
- **AIにカスタマイズを頼むときだけ、流れが変わります。** 渡したフォルダの中身は、あなたが契約しているAI事業者に送られます。AIかけこみ寺には何も渡りません。
- お客様の情報を扱うなら、**入力が学習に使われない設定・プラン**（ChatGPTの学習オフ設定、Claude・Geminiなどの有料/法人プラン等）で使うことをおすすめします。条件は各社で変わるため、提供元の案内を確認してください。
- **AIに改造を頼むときは、お客様の情報が入っていない状態で渡してください。** 画面の「グループを全部消す」を押してからフォルダを渡すのが安全です。
- 「保存ファイル」にはお名前や男女の別が入ります。**個人情報として扱ってください**（共有フォルダに置きっぱなしにしない、不要になったら消す）。`.gitignore` で `*_座席表データ.json` をgitの管理対象外にしてあります。

詳しくは [`manual.html` の8章冒頭](manual.html#data-flow) にあります。

## カスタマイズ（プログラムの知識は不要です）

**Claude Code などのAIコーディングエージェント** に、下の文をそのまま貼り付けてください。

```
「バス座席表メーカー」というオープンソースのツールを、自分用に手直ししたいです。
まず、ソースを手元に用意してください。

- 置き場所: https://github.com/ai-kakekomi/bus-seat-maker
- 手元にまだ無ければ、作業用フォルダに git clone してください
- すでに手元にあれば、git pull で最新に更新してください（私が加えた変更は消さないでください）
- 用意できたら中身をひととおり読んで、このツールが何をするものか、
  席の決め方がどのファイルに書いてあるかを、日本語でかんたんに教えてください
- 最後に、ローカルサーバー（例: python3 -m http.server 8000）で開いて、
  画面がちゃんと表示されることを確認してください
- 作業を始める前に、渡したフォルダにお客様の個人情報や社外秘の情報が
  入っていないか、私に確認してください
```

そのあとは、やりたいことを日本語で頼むだけです。

- 「中型バスの9列33席を選べるようにして」
- 「業務席を最前列の左1席だけにして」
- 「前席オプションの範囲を前から5列目までにして」
- 「2日目は前後ではなく左右を入れ替えるようにして」
- 「『車いすをご利用』のチェックを足して、その方は最前列の通路側にして」
- 「座席表の見出しに集合時刻の欄を足して、印刷にも出して」

改造したら「テストを流して、全部通ることを確認して」と頼んでください。おかしくなったら「さっきの変更を全部取り消して」で戻ります。

詳しい手順は [`manual.html` の8章](manual.html#ask-ai) にあります。
