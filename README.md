# バス座席表メーカー（bus-seat-maker）

バスツアーの**添乗員向け**の座席表ジェネレータです。申し込みグループを順番に入れると、席を自動で割り振り、A4縦・1日1ページで印刷できる座席表にします。

手書きで作っていた「グループごとにマーカーで大きく囲み、その中に名前と人数を1回書く」座席表を、画面の上で作れるようにしたものです。グループの席は必ず**ひとつながりのブロック**（四角、またはL字）になり、斜めに泣き別れることはありません。

非営利団体 **AIかけこみ寺** が制作し、**MITライセンス** で公開しています。

- 座席図は**一般的な大型観光バスを想定した簡略図**です。実在の車両とは異なる場合があります。

## 動かし方

このツールは**完全な静的サイト**です。サーバーもデータベースも外部ライブラリも使いません。入力した内容は**あなたのブラウザの中（localStorage）だけ**に保存され、インターネットには一切送信されません。

`index.html` をブラウザで開くだけで動きます（ダブルクリックで開く `file://` でも動作します）。

ローカルサーバー経由で開きたい場合は次のとおりです。

```
python3 -m http.server 8000     # Mac / Linux（Windows は python -m http.server 8000）
npx --yes http-server -p 8000   # Node.js を使う場合
```

そのあとブラウザで <http://localhost:8000/> を開きます。

対応ブラウザ：PC の Chrome / Edge 最新版。

### 使う流れ

1. 「見本を入れてみる」を押して、動きを確かめる
2. ツアー名・号車・日数・出発日を入れる
3. 座席の形（11列45席／12列49席）を選ぶ
4. 申し込みグループを**申し込み順に**追加する（人数・男女・前席オプション。名字の欄はお名前を出す設定にしたときだけ出ます）
5. 座席表が自動でできる。必要なら**グループの席→行き先**の順に2回押して手で動かす（1席ずつ入れ替えるモードもあります）
6. 「印刷する」でA4縦・1日1ページの座席表を印刷／PDF保存する

**操作方法がわからないときは、まず [`manual.html`](manual.html) を開いてください。** このREADMEより平易に説明しています。

## 席の決め方（ルール11本）

席の割り当ては `js/seat.js` の純粋関数にまとまっています（画面の処理とは分離しているので、テストから直接呼べます）。

| # | ルール | 実装 |
|---|---|---|
| 1 | 最前列の運転席側（右）2席は業務席。お客様は配置しない | `buildLayout()` の `isCrew` |
| 2 | 最後部列のみ5席、それ以外は4席（左2＋右2） | `buildLayout()` |
| 3 | 申し込み順に前から詰める | `assignDay()` のグループ順 |
| 4 | **グループは必ずひとつながりのブロックに入れる**（四角＞L字。斜めだけの接続は不可） | `findRect()` / `shapeCandidates()` |
| 5 | 奇数人数はL字で空席ゼロに収める。L字が作れないときだけ、四角＋取り置き空席にする | `shapeCandidates()` / `MAX_WASTE` |
| 5の2 | **1名グループの枠は必ず1席ぶん**。相席回避で空ける席は枠の外に出す | `count <= 1` / `blocked` |
| 6 | 前席オプションのグループを先に、前から3列目までに配置。溢れたら以降の列へ回し警告 | `FRONT_ROWS` / `front-overflow` |
| 7 | 相席が発生する場合、男女が同席にならないよう性別を合わせる | `planMembers()` / `genderCompatible()` |
| 8 | 空席に余裕がある（奇数グループの端数を空席で吸収できる）ときは相席を作らない | `shouldAvoidSharing()` |
| 9 | 日ごとにグループの並べ始めを1周ぶんの `d/日数` だけずらす（巡回シフト）。**配置そのものは常に前から詰める**（後方に空白の島を作らない）。前席オプション組は**前3列のなかで**別に巡回する | `startIndexForDay()` |
| 10 | 使われない後方のかたまりは、まとめて1つの「自由席」の枠にする | `freeAreaBlock()` |
| 11 | 隣接（左右・前後）するグループが同色にならないよう6色を割り当てる | `buildColors()` |

### ブロックの形の選び方

`findRect()` は「いちばん前の列」を最優先し、同じ列のなかでは次の点数がいちばん小さい形を選びます。候補は **四角** と、**四角の角を1〜2席欠けさせたL字**（欠けたあともひとつながりであることを確認）です。

```
点数 = 横幅ペナルティ + 列数 × 0.4 + 取り置き空席 × 0.6 + 欠けさせた席 × 0.15
横幅ペナルティ: 2席=0 / 4席=0.5 / 3席=3 / 1席=4
```

欠けの penalty（0.15）は空席の penalty（0.6）より小さいので、**ぴったりの四角 ＞ L字（空席ゼロ）＞ 取り置き空席つきの四角** の順に選ばれます。結果は次のとおりです。

| 人数 | 形 | 取り置き空席 |
|---|---|---|
| 1名 | 1席 | なし（枠の外に相席回避の空席を1つ確保） |
| 2名 | 2席×1列 | なし |
| 3名 | **L字**（2席＋そのとなりの1席） | なし |
| 4名 | 2席×2列の正方形 | なし |
| 5名 | **L字**（2席×3列から1席欠け） | なし |
| 6名 | 2席×3列 | なし |
| 8名 | 4席×2列（通路を跨ぐ） | なし |

通路を跨ぐブロックは、左右をひとつながりの枠で囲みます（通路のすじにも線を渡します）。ひとつながりの形にできないときだけ、入るかぎり大きい形に分割し（各断片は同色の枠で表示）、`split` の注意を出します。表示ラベル（名前＋人数の丸数字）は**ブロックの中でいちばん広いところに1回だけ**描きます。

枠の描画は矩形前提をやめ、**セル集合の外周をなぞる方式**（各セルの、隣が同じブロックでない辺にだけ線を引く）にしてあるため、L字でもコの字でもそのまま囲めます。

### 手動調整の2モード

「自動で席を決める」は**完全リセット**です。`recompute()` が `selection` / `selectedSeat` / `manualEdited` を初期化し、`state.groups` を**ディープコピーしてから** `S.assign()` に渡すため、前回の結果が参照経由で混ざることはありません（全日ぶんを作り直します）。

| モード | 操作 | 中身 |
|---|---|---|
| **グループごと動かす**（既定） | グループの席をタップ → 行き先をタップ | 別グループをタップ＝`swapGroups()` で両者を再配置／空席をタップ＝`moveGroup()` でその席を起点に再配置 |
| 1席ずつ入れ替える | 席をタップ → 入れ替え先をタップ | `swapSeats()` |

`moveGroup()` / `swapGroups()` は、指定の席を起点に置けなければ**その列から後ろへ、なければ前へ**戻って近い場所を探します。どうしても置けない場合は**元の配置に巻き戻して**失敗を返すため、操作で座席表が壊れることはありません。

#### 失敗理由コード

`swapSeats()` / `moveGroup()` / `swapGroups()` は `{ ok, reason, groupId, size, seatId }` を返します。**日本語の文にするのは `app.js` の責務**で、`seat.js` は文言を持ちません。

| reason | 画面に出る文 |
|---|---|
| `crew-seat` | 業務席にはお客様を配置できません。 |
| `same-seat` | 同じ席が選ばれています。別の席を選んでください。 |
| `same-group` | 移動先が同じグループの席です。別の場所を選んでください。 |
| `no-room` | お客様E（4名）が入るまとまった空きがありません。ほかの場所を試してください。 |
| `no-room-swap` | お客様E（4名）が入るまとまった空きがないため、入れ替えできませんでした。 |
| `not-seated` | まだ座席が決まっていないグループです。先に「自動で席を決める」を押してください。 |
| `group-not-found` / `seat-not-found` | 対象が見つかりませんでした。もう一度選び直してください。 |

成功時は `reason` が `moved` / `swapped` になり、`warnings`（分割など）があればそのメッセージを表示します。

#### 手動編集後の見直し（`inspectDay()`）

手で直した日だけ `inspectDay(layout, groups, day)` で点検し、**その日の座席表の直下**に黄色の枠で表示します（**印刷には含めません**。`.manual-check` を `print.css` で非表示）。どの日の話かが位置で分かるため、日番号の接頭辞は付けません。自動割り当ては仕様を守るため直後は0件で、「自動で席を決める」を押すとクリアされます。

| type | メッセージ例 |
|---|---|
| `front-out` | お客様A（前席オプション）が4列目以降にいます。 |
| `mixed-gender` | 7列目で男女が相席になっています。 |
| `split` | お客様Bの席が2か所に分かれています。 |
| `seat-count` | お客様C（4名）の席が3席しかありません。 |
| `crew-seat` | 1列目の業務席にお客様が座っています。 |

編集をブロックはしません（あくまで注意喚起）。同一内容は1件にまとめ、**メッセージには実名を出さず記号のみ**を使います。

### 日ごとの席替え（巡回シフト）

前席オプションを除いたグループの並びを**輪（循環リスト）**とみなし、d日目（0起点）は全体の `d / 日数` だけ進んだ位置から並べ始めます。開始位置は**人数ベース**で、累積人数が `総人数 × d / 日数` に達する最初のグループの切れ目です（グループを途中で切ることはありません）。

```
例：8組×4名＝32名
  2日ツアー → 開始グループ 0, 4       （半周ずつ）
  4日ツアー → 開始グループ 0, 2, 4, 6 （4分の1ずつ）
例：9組×3名＝27名
  3日ツアー → 開始グループ 0, 3, 6    （3分の1ずつ。全員が前・中・後を1日ずつ）
```

2日ツアーは半周シフトとなり、従来の「前後入れ替え」とほぼ同じ結果になります。配置は**どの日も前から詰める**ため、後方に不自然な空白の島はできません。

**前席オプション組も同じ考え方で巡回します。**ただし回るのは前3列の範囲内だけで、前3列を出ない保証は維持されます（溢れたときの警告仕様も従来どおり）。前席組が1組だけなら開始位置は常に0となり、実質固定になります。

### 表示ラベルの規則

- 既定は自動ラベル `お客様A`（申し込み順の記号。26組を超えると `AA`・`AB`…）。**個人名はPIIなので既定では出しません**。この設定では**名字の入力欄そのものを画面に出しません**
- 実名表示をONにしたときだけ名字の欄が現れ、`名字＋様` で表示します。**同姓が複数いる場合は自動でフルネーム表示**に切り替わります（OFFに戻しても入力値は保持）
- グループ人数は丸数字（`②` = 2名）で、**ブロックの枠内に1回だけ**表示します
- 座席マスは**中身によらず固定サイズ**（画面・印刷とも `grid-template-columns` / `grid-auto-rows` を固定値化）。長いフルネームでもマスが伸縮せず、ラベルは省略記号（ellipsis）で吸収します
- 前席オプション組の席は**斜めストライプ**（`repeating-linear-gradient`）。グループ色はそのままなので識別性は変わらず、白黒印刷でも縞で判別できます。凡例に「斜めストライプ＝前席オプション」を自動で追記（前席組がいる日だけ）
- 男女の印は**各席の右下すみに固定**（ラベルは半透明・1行で中央やや上）。1席だけのブロックでもラベルと重ならず、画面・印刷とも全席で性別が読めます
- **組の記号は英字、人数は丸数字**と表記を分けています（`お客様C ③` = 3組目・3名）。どちらも数字だと見間違えるため

### 設計上の判断

- **既定で個人名を出さない**：座席表は紙で持ち歩くもので、落とすことも置き忘れることもあります。番号での運用を既定にし、実名表示は明示的なトグルにしました。
- **グループは1つの大きな枠**：実物（手書きの座席表）は座席ごとではなくグループ全体を1本のマーカーで囲み、その中に名前と人数を1回書きます。座席ごとにラベルを繰り返すより、現場で読み取りやすいのでこの形にしました。
- **四角に縛らずL字も使う**：実物でもL字囲みが使われています。3名・5名はL字なら空席ゼロで収まり、席の無駄も「人数の誤読」も起きません。
- **1名は1席の枠**：2席の枠で囲むと2人組に見えてしまうため、枠は必ず1席ぶん。相席を避けるために空ける隣席は、枠の外のふつうの空席として描きます。
- **日ごとの席替えは「順番をずらす」で行う**：後ろから詰めると後方に不自然な空白の島ができるため、配置は常に前詰めのまま、グループの並べ始めだけを人数の割合ぶんずらします（巡回シフト）。2日でも3日でも同じ考え方で扱えます。
- **お名前の入力欄は既定で出さない**：実名表示をONにしたときだけ名字の欄が現れます（入力済みの値はOFFにしても保持）。番号運用が既定であることを、画面の作りからも伝えるためです。
- **前席オプションは前3列のなかで巡回**：料金をいただいている以上どの日も前3列に置くのが筋ですが、複数組あるのに毎日同じ席では不公平なので、前3列の範囲内で日ごとに順番を回します。
- **性別未入力は誰とでも相席可**：分からないものを勝手に決めつけないための扱いです。相席が起きそうなときは入力してください。
- **判定できないことは判定しない**：年齢・体調・個別のご要望などは機械には分かりません。手動入れ替えで添乗員が最後に決める前提です。

## 情報がどこに行くか

- **ふだんの利用は端末内で完結します。** 静的ファイルだけで動き、送信先のサーバーもデータベースもありません。入力したお名前・人数・男女の別も、作った座席表も、ブラウザの外には出ません（保存先はlocalStorageのみ）。
- **AIにカスタマイズを頼むときだけ、流れが変わります。** 渡したフォルダの中身は、あなたが契約しているAI事業者に送られます。AIかけこみ寺には何も渡りません。
- お客様の情報を扱うなら、**入力が学習に使われない設定・プラン**（ChatGPTの学習オフ設定、Claude・Geminiなどの有料/法人プラン等）で使うことをおすすめします。条件は各社で変わるため、提供元の案内を確認してください。
- **AIに改造を頼むときは、お客様の情報が入っていない状態で渡してください。** 画面の「グループを全部消す」を押してからフォルダを渡すのが安全です。
- 「保存ファイル」にはお名前や男女の別が入ります。**個人情報として扱ってください**（共有フォルダに置きっぱなしにしない、不要になったら消す）。`.gitignore` で `*_座席表データ.json` をgitの管理対象外にしてあります。

詳しくは [`manual.html` の8章冒頭](manual.html#data-flow) にあります。

## カスタマイズ（プログラムの知識は不要です）

**Claude Code などのAIコーディングエージェント** に、下の文をそのまま貼り付けてください。

```
「バス座席表メーカー」というオープンソースのツールを、自分用に手直ししたいです。
まず、ソースを手元に用意してください。

- 置き場所: https://github.com/ai-kakekomi/bus-seat-maker
- 手元にまだ無ければ、作業用フォルダに git clone してください
- すでに手元にあれば、git pull で最新に更新してください（私が加えた変更は消さないでください）
- 用意できたら中身をひととおり読んで、このツールが何をするものか、
  席の決め方がどのファイルに書いてあるかを、日本語でかんたんに教えてください
- 最後に、ローカルサーバー（例: python3 -m http.server 8000）で開いて、
  画面がちゃんと表示されることを確認してください
- 作業を始める前に、渡したフォルダにお客様の個人情報や社外秘の情報が
  入っていないか、私に確認してください
```

そのあとは、やりたいことを日本語で頼むだけです。

- 「中型バスの9列33席を選べるようにして」
- 「業務席を最前列の左1席だけにして」
- 「前席オプションの範囲を前から5列目までにして」
- 「日ごとの席替えを、順番をずらすのではなく左右の入れ替えにして」
- 「L字ではなく、必ず四角い枠になるようにして」
- 「『車いすをご利用』のチェックを足して、その方は最前列の通路側にして」
- 「座席表の見出しに集合時刻の欄を足して、印刷にも出して」

改造したら「テストを流して、全部通ることを確認して」と頼んでください。おかしくなったら「さっきの変更を全部取り消して」で戻ります。

詳しい手順は [`manual.html` の8章](manual.html#ask-ai) にあります。
